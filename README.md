# trabalho.estacio

Projeto de estudo de HTML, CSS e JavaScript: página educativa sobre cibersegurança, com autoria original de Windsor Kayck e Andrey Tarata.

## Executar

Abra `index.html` no navegador. Opcionalmente, nesta pasta, execute `python -m http.server 8000` e visite http://localhost:8000.

## Organização

- `index.html`: entrada e catálogo do repositório.
- `style.css`: estilo do catálogo.
- [trabalho andrey/html/index.html](trabalho%20andrey/html/index.html): página original; seus endereços foram preservados.
- `projetos/`: exemplos independentes (disponível no repositório LANGING-PAGE).

## Dependências do trabalho original

Vídeos do YouTube e o formulário FormSubmit dependem de serviços externos. Algumas versões referenciam arquivos MP4 que não foram incluídos no repositório. Esses recursos não são necessários para os novos exemplos. O formulário original mantém o destinatário existente.
